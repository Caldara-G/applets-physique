Calcul d'incertitudes

MP* Malherbe

Données

Valeurs séparées par des espaces, des retours à la ligne ou des points-virgules. La virgule décimale est acceptée.

La valeur vraie est supposée certainement comprise dans [x − Δ, x + Δ], d'où u = Δ/√3. Pour une notice du type « 0,5 % + 2 digits », Δ = 0,5 % de la lecture + 2 fois la valeur du dernier digit.

          Rappels utilisés par l'applet
          • Type A: meilleure estimation ȳ (moyenne), incertitude-type u = s/√N, où s est l'écart-type expérimental (division par N − 1).
          • Type B: si la valeur est certainement dans [x − Δ, x + Δ], u = Δ/√3. Si les deux évaluations sont faites, u = √(uA² + uB²).
          • Somme y = Σ ci xi: u(y)² = Σ ci² u(xi)². Produit y = k Π xiαi: (u(y)/y)² = Σ αi² (u(xi)/xi)².
          • Monte-Carlo: la valeur est f(valeurs mesurées); l'incertitude-type est l'écart-type des N valeurs obtenues par tirages aléatoires des grandeurs.
          • Arrondi: l'incertitude-type est arrondie par excès à deux chiffres significatifs, la valeur est arrondie au même rang.
          • Écart normalisé: z = |x₁ − x₂| / √(u₁² + u₂²); les deux valeurs sont compatibles si z ≤ 2.
          • Régression: écart normalisé de chaque point au modèle, zi = (yi − a xi − b) / √(u(yi)² + a² u(xi)²). Le modèle est validé si |zi| ≤ 2 pour tous les points. Le coefficient r² n'est pas un critère de validation.
